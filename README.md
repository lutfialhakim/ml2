# Eksperimen Machine Learning — Dataset Ikan

Aplikasi Streamlit berisi eksperimen beberapa algoritma machine learning pada dataset ikan: **SVM**, **Decision Tree**, **Perceptron**, dan **K-Means Clustering**.

## Teknologi

- Python, Streamlit
- scikit-learn, pandas, NumPy, matplotlib, graphviz

## Menjalankan aplikasi

```bash
pip install streamlit pandas numpy scikit-learn matplotlib graphviz
streamlit run app.py
```
